# Lucide icons

The app bundles only the icons it uses as Android VectorDrawables. Paths are converted from Lucide SVG geometry, retaining rounded caps/joins and the 24×24 grid. No SF Symbols assets or fonts are included.

Source: [lucide-icons/lucide](https://github.com/lucide-icons/lucide), revision `d672fc43dbf60962d9d829e35bc3b3e5ed89a178`.

Included icons: wifi, radio, smartphone, tablet, bluetooth, house, settings, chevron-right, arrow-right, arrow-left, plus, lock-keyhole, check, eye, eye-off, x, refresh-cw, circle-question-mark, trash, circle-alert.

Local historical aliases: `ic_lucide_circle_help` → `circle-question-mark`; `ic_lucide_trash_2` → `trash`.

License and copyright notices are bundled in `android/app/src/main/assets/lucide-LICENSE.txt`. The launcher icon is an app-specific rounded blue tile with a Wi-Fi drawing.
